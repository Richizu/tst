# Решение проблем

### Обход сам выключается в фоне
Разрешите приложению работать в фоне: **Настройки → Работа в фоне → Оптимизация батареи** и, если есть, **Автозапуск** для вашей прошивки (Xiaomi, Huawei, Oppo, Vivo, Samsung). Не включайте «Экономный режим», если нужен автоматический перезапуск.

### Другой VPN перестал работать
Android разрешает только один VPN одновременно. Включение обхода отключает другой VPN и наоборот. Прокси Telegram работает и без VPN.

### YouTube не работает
1. На вкладке **Обход** нажмите **Подобрать способ** и дождитесь конца.
2. На главном экране нажмите **Открыть и проверить** — приложение будет перебирать способы, пока не найдёт рабочий.
3. Wi‑Fi и мобильная сеть — разные провайдеры: подбирайте способ в каждой сети отдельно.
4. На телевизоре официальный YouTube часто не работает через обход — выберите **SmartTube** в настройках.

### Telegram не подключается
- Нажмите **Подключить в Telegram** на вкладке Telegram и подтвердите прокси в самом Telegram.
- Если после выключения прокси Telegram не подключается — выключите прокси в Telegram: **Настройки → Данные и память → Прокси**.
- На Xiaomi/Huawei и т.п. включите **Не давать засыпать** на вкладке Telegram.
- Если Cloudflare работает плохо, задайте адреса дата-центров (например `2:149.154.167.220, 4:149.154.167.220`) или выключите Cloudflare.

### На телевизоре не появляется запрос VPN
Некоторые прошивки не показывают окно разрешения VPN. Выдайте его один раз с компьютера:
```
adb shell appops set com.richizu.fixrkn ACTIVATE_VPN allow
```

### Банк или другое приложение перестало работать
В режиме **Только выбранные приложения** (по умолчанию) остальные приложения идут напрямую. Если выбран режим «Все приложения», верните «выбранные» или уберите приложение из списка.

### Ошибка при установке обновления
Разрешите установку приложений из RichizuFixRKN: Настройки Android → Приложения → RichizuFixRKN → Установка неизвестных приложений.

### Как сообщить об ошибке
**Настройки → Журнал работы → Отправить** и приложите текст к задаче в [Issues](https://github.com/richizu/tst/issues).
